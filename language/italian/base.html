形容詞の変化

語尾が4つに変化する形容詞（第一類）

単数形と複数形に加え、男性名詞と女性名詞でも変化する。

性別と数 形容詞の形 例（イタリア語） 例（日本語訳）
男性単数 -o un fiore giallo 黄色い花（1つ）
女性単数 -a una maglietta gialla 黄色いTシャツ（1枚）
男性複数 -i fiori gialli 黄色い花（複数）
女性複数 -e magliette gialle 黄色いTシャツ（複数）

語尾が2つに変化する形容詞（第二類）

単数形と複数形でしか変化せず、男性名詞と女性名詞で同じ形を使用する。多くがこのパターン。

性別と数 形容詞の形 例（イタリア語） 例（日本語訳）
男性名詞（単数） -o un libro verde 緑の本（1つ）
女性名詞（単数） un gonna verde 緑のスカート（1つ）
男性名詞（複数） -i un libro verdi 緑の本（複数）
女性名詞（複数） un gonna verdi 緑のスカート（複数）

形が変化しない形容詞（不変形容詞）

    名詞の性別や数にかかわらず、一切形が変わらない形容詞も存在する。
  • blu（青い）
  • rosa（ピンクの）
  • beige（ベージュの）
  • viola（紫の）
    • など。
    外来語の形容詞。
  • sexy
  • sport
    • など。
